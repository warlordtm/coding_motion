# Coding Motion

A collection of interactive coding animations and visual experiments built with HTML, CSS and JavaScript.

This repository contains source code for projects featured in my programming and cybersecurity videos. Each project is self-contained and can be explored or run independently.

## Projects

| Project | Description | Source |
|---|---|---|
| [Cyber Threat Radar](projects/cyber-threat-radar/) | A visual simulation of a cybersecurity threat-monitoring interface. | [Open project](projects/cyber-threat-radar/) |
| [Password Strength Visualiser](projects/password-strength-visualiser/) | An interactive demonstration of how password length and unpredictability affect strength. | [Open project](projects/password-strength-visualiser/) |

## Running a project

1. Open the project folder.
2. Read its `README.md`.
3. Open `zencode.html` in a modern browser, or use a local development server if required.

## Repository conventions

- Each project keeps its own HTML, CSS, JavaScript and documentation.
- Standard HTML and CSS filenames are `zencode.html` and `zencode.css`.
- JavaScript filenames are specific to each project.
- Keep rendered videos and large media files outside this repository.
- Document each project's scope, limitations and setup instructions.
